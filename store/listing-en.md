## Detailed description (≤16000 characters)

```
LinguaLens makes foreign-language content readable: bilingual subtitles on video, bilingual paragraphs on the web, and subtitle files you can take with you.

■ Automatic bilingual subtitles
Open any YouTube video and LinguaLens fetches the caption track and translates it line by line. The translation sits above the original, appearing as the video plays — no subtitle file to upload. The subtitle box can be dragged anywhere on the player, double-clicked to reset, and its position is remembered.

■ Export subtitles in one click
Choose bilingual / translation only / original only, and export SRT or VTT. In bilingual mode the translation and the original share the same timeline, which is handy for note-taking, editing, or language study. If a video has no caption track, you can import a local SRT / VTT file and translate that instead.

■ Full-page bilingual translation on any site
Press Alt + A on any web page, or click "Translate this page" in the popup. Body paragraphs are translated and the translation is inserted right under each original paragraph in a soft highlight. "Restore original" removes every inserted node and leaves the page exactly as it was.

■ Works right after install — no API key
Translation is provided by a hosted service (Doubao doubao-seed-2-0-lite). No sign-up, no API key, no local server. If you prefer your own backend, point the extension at it in the options page.

■ Keyboard shortcuts
Alt + T — toggle bilingual subtitles
Alt + D — download bilingual subtitles
Alt + A — translate / restore the current page

■ Target languages
Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Spanish, French, German, Russian, Portuguese

■ Privacy
The extension only sends the text you asked to translate to the translation service. It does not collect accounts, browsing history, cookies, passwords or clipboard contents, shows no ads, and never sells data. The service does not store source text or translations; a short-lived in-memory cache speeds up repeated lines. Full policy: https://lingualens.coze.site/privacy

■ Known limitations
· Videos without a caption track cannot be auto-translated — import a local subtitle file instead.
· Full-page translation handles body text only, not text baked into images.
· Translation needs a network connection and the hosted service.

■ Who it is for
People watching technical talks and foreign-language videos, reading papers and docs in another language, who want the original and the translation side by side.
```
