## 简短说明（Short description，≤132 字符）

```
YouTube 字幕自动变双语，字幕框可拖动、一键导出 SRT/VTT；任意网页也能整页双语翻译。安装即用，无需配置。
```

## 详细说明（Detailed description，≤16000 字符）

```
LinguaLens 把「看外语内容」这件事变简单：视频出双语字幕，网页出双语对照，看完还能把字幕带走。

■ 自动双语字幕
打开 YouTube 视频即自动抓取字幕轨并逐句翻译，译文在上、原文在下，边看边出译文，不需要手动上传字幕文件。字幕框可按住拖动到画面任意位置，双击复位，位置自动记住。

■ 一键导出字幕
支持「双语对照 / 仅译文 / 仅原文」三种模式，导出 SRT 与 VTT 两种格式。双语模式下译文与原文写入同一时间轴，方便做笔记、二次剪辑或语言学习。抓不到字幕轨时，也能导入本地 SRT / VTT 文件照样翻译与导出。

■ 任意网页整页双语翻译
在任意网页按 Alt + A，或点击弹窗里的「翻译本页」，正文段落会逐段翻成双语，译文以浅色块插在原文下方，点「恢复原文」可完全还原，不会破坏页面结构。

■ 安装即用，不用配 API Key
翻译由云端服务提供（模型：豆包 doubao-seed-2-0-lite），装好就能用，不需要自己申请 Key、不需要本地起服务。想接自建服务，在设置页把服务地址改成自己的即可。

■ 快捷键
Alt + T：开关双语字幕
Alt + D：下载双语字幕
Alt + A：整页翻译 / 还原

■ 支持的目标语言
简体中文、繁体中文、English、日本語、한국어、Español、Français、Deutsch、Русский、Português

■ 关于隐私
扩展只把「你要求翻译的那段文字」发送到翻译服务；不收集账号、浏览历史、Cookie、密码或剪贴板内容，不投放广告，不出售任何数据。服务端不保存原文与译文，仅在内存中做短期缓存以加速重复内容。完整说明：https://lingualens.coze.site/privacy

■ 已知限制
· 视频没有字幕轨时无法自动翻译，可导入本地字幕文件；
· 整页翻译只处理正文段落，不翻译图片里的文字；
· 翻译依赖网络与云端服务，离线不可用。

■ 适合谁
看英文技术视频、追外语剧、读外文论文与文档，想把原文和译文放在一起看的人。
```
