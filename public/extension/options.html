TobyTranslate · YouTube 双语字幕

自动翻译 YouTube 视频字幕，双语对照显示，支持下载双语 SRT / VTT 字幕。

🎉 安装成功！打开任意 YouTube 视频，字幕会自动翻译成中文。建议先确认下方「翻译服务」连接正常。

翻译服务

本地启动的服务端默认地址为 http://localhost:5050，可在启动日志里确认端口。

尚未检测

翻译结果会显示在这里。

字幕显示

字幕框可以按住工具栏最左侧的 ⠿ 抓手拖动到任意位置，双击抓手复位；拖动后的位置会自动记住。

整页翻译

在任意网页按 Alt + A 或点击弹窗「翻译本页」，即可把正文逐段翻成双语；译文以浅色块插在原文下方，点「恢复原文」可完全还原。

使用说明

  1. 确认服务端已启动，并在上方「测试连接」中显示服务正常。
  2. 打开 YouTube 视频，等待右下角出现「AI 翻译中 x/y」提示。
  3. 译文会叠加显示在原字幕上方；按 Alt + T 可以随时开关。
  4. 点击插件图标，或按 Alt + D，即可下载双语字幕文件。

若提示「该视频没有可用的字幕轨道」，说明视频本身没有字幕；若提示字幕下载失败，可尝试刷新页面或换一个视频源。
